# Digital Payment Fraud Pattern Detection & Risk Scoring System

BCA Mini Project (Review I) — Presidency University, Bengaluru

An explainable, rule-based fraud detection system for digital payments (UPI, cards, wallets) 
that flags suspicious transactions, links related accounts into fraud rings using Union-Find, 
and assigns a traceable risk score — without AI/ML, per project requirements.
